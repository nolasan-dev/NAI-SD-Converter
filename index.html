自動補正、翻訳機能、および各AIツール特有の構文処理についての解説です。 Details on auto-correction, translation, and syntax handling for each AI tool.

■ 入力テキストの自動クリーンアップ（表記ゆれ補正） ■ Auto-Cleanup (Normalization)

  • 全角記号の半角化: 全角の括弧 （ ） ｛ ｝ ［ ］ は、AIが正しく認識できる半角記号に自動補正されます。Full-width to Half-width: Full-width brackets are converted to half-width.
  • 区切り文字の統一: 全角読点 、 やセミコロン ; ； などは、すべて標準の半角カンマ , に自動変換され、プロンプトが綺麗に整理されます。Separator Unification: Semicolons and full-width commas are normalized to standard commas.
  • 大文字・小文字の自動補正: `break` や `LORA` などの特殊構文は、正しく機能するように自動的に `BREAK` (大文字) や `<lora:...>` (小文字) に統一・補正されます。Case Normalization: Special syntaxes like `break` or `LORA` are automatically converted to their correct case (`BREAK`, `<lora:...>`) to ensure proper functionality.

■ 日本語の自動翻訳機能について ■ Japanese Auto-Translation

  • 入力プロンプトに日本語（ひらがな・カタカナ・漢字）が含まれている場合、Google翻訳APIを経由して、自動的に英語へ翻訳されてから構文変換が行われます。If Japanese characters are detected, the prompt is automatically translated to English via the Google Translate API before syntax conversion.
  • ※外部APIのサーバー混雑時など、通信に失敗した場合は翻訳をスキップし、日本語のまま変換結果を出力します。*If the external API fails or is congested, translation is skipped and the original text is used.

ネストされた重み
(括弧の重ね掛け) Nested Weights
(Stacked brackets) 		(((tag))) {{{tag}}} SD ⇔ NAI 自動変換SD ⇔ NAI Auto Convert
NovelAIは {} を1つ重ねるごとに 1.05倍 ([] は約0.95倍)。SDの () は 1.1倍 です。自動変換時、それぞれの倍率に合わせて近い数値になるよう括弧の個数（重ね掛け）が自動補正（または数値指定に変換）されます。 NovelAI multiplies by 1.05 for each {} ([] is ~0.95). SD's () multiplies by 1.1. During conversion, the weights are calculated and the number of stacked brackets is automatically adjusted (or converted to numeric weights) to match the closest multiplier.
